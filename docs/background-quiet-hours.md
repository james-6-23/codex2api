# 后台巡检暂停时段

在「设置 → Codex → 额度与调度 → 探针调度」添加多个每日暂停时段，点击「保存暂停时段」生效。所有时段固定使用北京时间 UTC+8，与浏览器及服务器时区无关。

- 时段左闭右开，00:00–07:00 表示 00:00 起暂停，07:00 恢复。
- 支持 23:00–07:00 跨午夜，重叠时段取并集，最多 32 个时段。
- 00:00–24:00 可全天暂停；起止相同会报错；空列表恢复全天巡检。
- 配置写入数据库并热生效，重启自动恢复；保存失败不会替换生效中的时段。
- 覆盖后台刷新循环的 Token 刷新、智能刷新队列、批量用量/恢复探针、重置边界探针、定时连通性测试、Codex 官方用量同步和列表自动回补。
- 手动刷新、手动探针、正常模型请求及请求异常触发的鉴权修复继续工作。已经开始的任务允许完成；排队的自动任务在发起前重新检查时段。
- 通用后台巡检到暂停结束时恢复；官方用量统计按自己的下一次定时检查恢复，暂停期间的定时连通性测试槽位不补跑。
- 不控制版本同步、其他渠道独立的维护服务、自动消耗额度功能或本地日志/缓存清理。

管理 API `PUT /api/admin/settings` 支持：

```json
{"background_quiet_hours":[{"start":"00:00","end":"07:00"},{"start":"12:00","end":"13:00"}]}
```

`GET /api/admin/settings` 返回同一数组。省略字段保留已有配置，空数组清除。数据库 SQLite/PostgreSQL 均以 `background_quiet_hours` JSON 文本持久化。
