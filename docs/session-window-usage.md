# 账号窗口平均使用时长

人物画像的 NewAPI 用户详情与账号状态页使用同一个统计口径：账号侧根会话窗口的一次占用周期，从账号窗口接纳开始，到该周期最近一次已结束请求的时间跨度。期间等待下一轮输入的时间属于使用跨度，但窗口释放后的空闲时间不属于。

- 根窗口与相关子代理使用同一个周期标识；免窗口统计的后台请求不计入。
- 闲置到期或手动释放后再次接纳，即使账号和根会话相同，也创建新的周期。请求发出前固定周期，晚结束的旧请求不会延长新的周期。
- 在运行时缓存保留了账号窗口状态的情况下，重启恢复同一个周期。已写入数据库的统计不会因重启清空。
- NewAPI 用户按已验证的平台与用户 ID 隔离，汇总其使用过的账号窗口周期；切换账号的周期分别统计。
- 新的 `account_session_usage_periods` 表通过原有用量日志批量事务写入，每批按账号与周期去重。更新只保留最早开始和最晚结束，不累加重试次数或请求耗时。
- 历史记录没有真实周期标识，不能可靠还原释放边界，因此不回填推测时长。无样本显示 `-`，而不是 0 秒。升级时已经活跃的旧窗口从开始采集后计时。
- 账号状态的原有窗口数量统计口径保持不变。平均时长按新增的占用周期样本计算，而不是用历史根窗口数量作分母。
- 表格首行统计全部筛选账号，分页不影响合计。数量列为每账号平均；时长为所有有效周期时长之和除以周期数；最近活动取最新时间，不平均时间戳。

该数据只用于运营观察，不参与模型计费、用户限额、账号窗口准入或风控评分。
