# 手动会话锁与窗口 500 标记

在人物画像的 NewAPI 用户详情中，每个活跃窗口右上角提供“锁定会话”，确认后变为“解除手动锁”。

- 锁定以已验证的 NewAPI 平台、用户 ID 和根会话为范围。后续主请求和已归属此根的子请求返回 HTTP 400，错误码为 `conversation_manually_locked`；WebSocket 返回对应的错误帧。已发出的请求不强制中断，其他窗口不受影响。
- 手动锁不增加 CYB/BIO 命中、惩罚次数或用户冷却，也不冻结账号。手动解锁不会撤销已有的自动风控限制。
- 创建时使用当前会话锁配置的有效期，持久化到数据库。重启不解除锁，重复点击不会延长已有锁；到期自动失效。活跃窗口消失后，详情中仍保留未到期手动锁的解锁入口。
- 接口必须匹配当前窗口的到期时间，过期卡片或同根重新创建的旧卡片不能直接发起锁定，需要刷新后确认。

绑定账号右侧的红色 `500` 标记表示本窗口在该账号上发生过 HTTP 500。悬停可查看最近时间，不暴露上游原始报错。重试后成功仍保留历史标记；502、503 等其他状态不算作 500。

标记按平台、用户、根会话、账号和窗口创建批次隔离；窗口过期重建、账号切换不会串用标记，旧请求晚结束也不会污染新窗口。只记录升级后、已接纳到用户窗口的请求，不从历史日志猜测回填。数据随原有日志批量写入，在详情刷新或重新打开后显示。窗口到期后不再展示标记，后续批量写入 500 标记时清理已过期记录。
